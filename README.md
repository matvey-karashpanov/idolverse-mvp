# IDOLVERSE

IDOLVERSE — веб-каталог K-pop, C-pop и J-pop исполнителей и музыкальных групп.

- **Сайт:** https://matvey-karashpanov.github.io/idolverse-mvp/
- **GitHub:** https://github.com/matvey-karashpanov/idolverse-mvp

## Возможности

- Главная страница с подборками артистов, групп и новостей.
- Каталоги артистов и групп с поиском и фильтрами.
- Страницы профилей артистов и групп с фотографиями и информацией.
- Лента новостей.
- Форма обратной связи для предложений и исправлений.
- Административная панель для управления артистами, группами, новостями и обращениями.

## Технологии

React, TypeScript, Vite, Redux Toolkit, React Router, CSS, Vitest и Testing Library.

## Запуск проекта

Требуется Node.js и npm.

```bash
npm ci
npm run dev
```

Vite выведет адрес локального сайта в терминале.

## Проверка проекта

```bash
npm test
npm run build
```

Дополнительно доступны команды `npm run preview` для просмотра production-сборки и `npm run format:check` для проверки форматирования.

## Данные и ограничения

Это frontend MVP. Данные каталога и обращения хранятся локально в браузере (`localStorage`). Поэтому изменения не синхронизируются между разными пользователями или устройствами.

Вход администратора демонстрационный и не является безопасной серверной авторизацией. Для общей базы данных, защищённой авторизации и постоянного хранения данных потребуется backend.

## Публикация

Проект настроен для публикации на GitHub Pages через GitHub Actions. После отправки изменений в основную ветку результат сборки публикуется автоматически, если для репозитория включён GitHub Actions в настройках Pages.
